# Screenshot Assets

The application source, tests and documentation are tracked in this GitHub repository. Historical UI screenshots from the supplied Phase 1–4 source archives are **not yet committed** because they are large binary evidence files. They are preserved in the complete downloadable source ZIP shared in this chat.

Do not treat their absence as proof that UI smoke tests were rerun on this GitHub branch. Follow `infra/smoke/` to generate new screenshots and revalidate the functional gate.
